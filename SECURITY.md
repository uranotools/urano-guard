# Security Policy

## 🛡️ Supported Versions

We provide security updates and patches for the following versions of `@urano/guard`:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## 🚨 Reporting a Vulnerability

We take the security of `@urano/guard` and the applications protected by it seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

### Reporting Channels
Please report security vulnerabilities by emailing:
* **Email:** `security@urano.ai` or `cyber-research@urano.dev`

### What to Include
To help us triage and resolve the issue quickly, please provide:
1. **Description of the vulnerability** (e.g., bypass in regex heuristic, race condition in cache, replay evasion).
2. **Proof of Concept (PoC)** with reproducible payload or script.
3. **Affected versions** and target runtime (Express, Fastify, Edge, etc.).
4. **Potential impact** and proposed mitigation (if available).

### Response Timeline
- **Initial Acknowledgment:** Within **24 hours**.
- **Assessment & Triage:** Within **48 hours**.
- **Fix & Advisory Release:** Critical patches are typically published within **5 business days**.

We follow responsible disclosure practices and will publicly credit your contribution in the security release notes.
